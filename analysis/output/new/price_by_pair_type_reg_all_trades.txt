# A4. Signed price deviation by trader-pair type (all_trades)
# Data: trades_panel.csv (executed trades, rounds 1-12 of the Carbon Trading stage, 10 sessions).
# signed_diff = price - eq_price (eq_price in {3, 6, 9} is the theoretical competitive permit price = matched tax rate);
# rel_dev = price / eq_price - 1; mins = seconds / 60 within the 120-second trading window.
# Samples: 'iqr_filtered' = existing per-session-round IQR outlier rule of run_trade_mkt_reg.py; 'all_trades' = no filter.
# Pair types: Db_Ss = dominant buyer / small seller, Sb_Ds = small buyer / dominant seller, Db_Ds = both dominant; base = small / small.
# Model (1) absorbs session x round fixed effects (C(cluster_round), not printed); *_eq terms are pair x equal-allocation interactions.
# Hypotheses: pair premium under grandfathering, under equal allocation, and their difference.
# Standard errors clustered by session_code; stars use the wild-cluster-bootstrap p-value: * p<.05, ** p<.01, *** p<.001.
# p (cluster, normal): statsmodels cluster-robust p with a normal reference, the convention of the existing tables.
# p (cluster, t G-1): same statistic with a t(G-1) reference.
# p (wild cluster boot): restricted wild cluster bootstrap (Cameron-Gelbach-Miller 2008), Webb six-point weights unless stated.
