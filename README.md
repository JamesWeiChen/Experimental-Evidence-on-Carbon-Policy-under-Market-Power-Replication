# Replication package for "Cap or Tax? Experimental Evidence on Carbon Policy under Market Power with Real Emissions"

**Authors:** Wei James Chen (National Taiwan University) and Yating Chuang (Academia Sinica)
**Package prepared:** 2026-10-30, against manuscript version `e263f30` (GitHub, "Updates from Overleaf")
**Registration:** AEA RCT Registry, AEARCTR-0016787
**Ethics approval:** National Taiwan University Behavioral and Social Sciences Research Ethics Committee, protocol 202312HS033
**Funding:** National Science and Technology Council (Taiwan)

## Overview

The paper reports a 150-subject laboratory experiment (10 sessions × 15 subjects) in which markets of three dominant and twelve small firms face a no-policy baseline, a carbon tax, and cap-and-trade with a multi-unit continuous double auction for permits. Initial permit allocation (grandfathering vs. equal) varies between sessions.

This package contains the de-identified raw oTree exports, the Python code that turns them into analysis panels, and the code that produces every table and data figure in the paper. A single command (`python run_all.py`) regenerates all outputs in about one minute on a laptop.

### Details on each data source

All data were collected by the authors in laboratory sessions run with oTree (Chen, Schonger and Wickens, 2016) at the Taiwan Social Sciences Experimental Laboratory (TASSEL), National Taiwan University, between 2025-09-10 and 2025-11-13. Each session produced one oTree "all apps wide" export (one row per subject, one column per app × round × field).

**Direct identifiers removed.** At the end of each session subjects entered payment information (name, school, student ID, national ID number, address, postal code, residence-permit/passport number, nationality, length of stay) on the `Stage_Payment_Info` page. These fields were used only to pay subjects and are not used in any analysis. They were removed from the deposited files with `tools/deidentify_raw.py`; every other cell is byte-for-byte identical to the original export. Re-running the full pipeline on the original files and on the de-identified files gives identical analysis panels. The original identifiable files are retained by the authors under the IRB protocol and are not distributed.

The post-experiment survey (`Stage_Survey`) answers, including age, gender, year of study and major, are kept; they are not linked to any identifier.

## Description of programs/code

- `run_all.py`: master script. It runs every script below in order and writes each script's console output to `logs/`.
- `build/code/gen_subj_and_group_panel.py`: reshapes the wide oTree exports into the subject-level panel (`subj_lv_panel.csv`) and the market-level panel (`group_lv_panel.csv`). It computes surplus, social-optimum benchmarks and policy indicators, and writes to `build/output/` and `analysis/input/`.
- `build/code/gen_trade_panel.py`: parses executed trades and submitted offers from the Carbon Trading stage into `trades_panel.csv` and `offers_panel.csv`.
- `analysis/code/reg_utils.py`: regression and table helpers (OLS with HC3 and session-clustered SEs, Wald tests, coefficient plots, wild cluster bootstrap).
- `analysis/code/theory_benchmark_utils.py`: theoretical (competitive and Hahn dominant-firm) benchmark positions.
- `analysis/code/gen_firm_net_trade_plot.py`: firm net-trade figure (actual vs. theory).
- `analysis/code/gen_trade_seconds_vs_price_diff.py`: permit price vs. time-in-round figures.
- `analysis/code/run_group_lv_reg.py`: market-level regressions (samples `all`, `tax`, `trade`, `policy`) and the efficiency decomposition (A8).
- `analysis/code/run_subj_lv_reg.py`: firm-level regressions (dominant vs. small firms) and unused-permit and shortfall diagnostics (A7).
- `analysis/code/run_trade_mkt_reg.py`: permit-price regressions and trading-friction diagnostics.
- `analysis/code/gen_summary_table_cells.py`: **added for this package.** It collapses the A7/A8 outputs into the exact cells of the welfare-decomposition (Panel A) and permit-shortfall tables, which were previously assembled by hand.
- `tools/deidentify_raw.py`: removes direct identifiers from the original exports. The authors ran it once; replicators do not need to run it.

Changes relative to the authors' working copy: in `reg_utils.py`, `gen_firm_net_trade_plot.py` and `gen_trade_seconds_vs_price_diff.py`, copying outputs into the authors' LaTeX folder (`doc/input/`) now happens only if that folder exists. No estimation code was changed.

## Instructions to replicators

1. Install the software environment as described above.
2. From this folder, run `python run_all.py`.
3. Outputs appear in `analysis/output/` (main tables and figures) and `analysis/output/new/` (appendix analyses). Logs appear in `logs/`.

Paths are relative to each script's location, so the package runs from any directory without edits. Each script also runs on its own (for example `python analysis/code/run_trade_mkt_reg.py`) once the build step has run.

The oTree source code of the experiment is not included in this package. The full subject instructions, interface screenshots and the comprehension quiz are reproduced in the paper's appendix. The code in this package starts from the oTree data exports.
